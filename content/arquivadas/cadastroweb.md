## Como fazer o cadastro na plataforma de cursos de extensão da USP

1.  Acesse o link [https://cursosextensao.usp.br/login/signup.php](https://cursosextensao.usp.br/login/signup.php)
2.  Crie sua conta utilizando seu CPF e o código de convite: **codificadas2024**
3.  Uma vez logada no site, você verá todos os cursos de extensão que a USP oferece no site. Você pode procurar o nosso curso (São Paulo > IME > Computação) ou simplesmente clicar em [https://cursosextensao.usp.br/course/view.php?id=3988](https://cursosextensao.usp.br/course/view.php?id=3988)
4.  Na seção “Autoinscrição (Aluno)” insira o código de convite: **codificadas202**4
5.  Pronto, bem vinda ao curso!

## Como criar uma conta no CodePen

O CodePen é uma ferramenta online de desenvolvimento web. No mesmo ambiente é possível editar códigos HTML, CSS e JavaScript (esse último não será abordado no curso), tudo isso direto do navegador! Devido sua praticidade e simples uso, utilizaremos o CodePen ao longo do curso. Para utilizá-lo o usuário precisa de uma conta na plataforma. Vamos ao passo a passo:

1.  Acesse o site do CodePen pelo link [codepen.io](https://codepen.io/)
2.  Vá até o botão verde escrito “Sign Up” no canto superior direito para criar uma nova conta. Caso você já tenha uma conta na plataforma, entre no botão “Log In” ao lado.

![](/assets/img/blog/cadastroweb-inline-1.jpg)

3.  Na tela seguinte crie sua conta como preferir: através do email pessoal, conta Google, Github ou Facebook.
4.  Pronto! Sua conta foi criada e você está preparada para realizar as atividades!

![](/assets/img/blog/cadastroweb-inline-2.jpg)

## Criando novos Pens

1.  Para criar um novo Pen vá ao menu do canto superior direito clique em “New Pen” para gerar um novo ambiente.

![](/assets/img/blog/cadastroweb-inline-3.jpg)

2.  Dê um nome para o seu Pen no canto superior esquerdo e salve ele.
3.  Você pode acessar todos os seus Pens indo no mesmo menu anterior e clicando em “Your Work”.

## Como entregar a atividade no Moodle

1.  Após terminar a atividade proposta, copie o link do seu Pen pela barra do navegador ou no botão “Share” do canto inferior direito.
2.  Abra o Moodle e navegue até a página de entrega da aula.
3.  Vá em “Adicionar tarefa”.
4.  Cole o link na caixa de texto. Em seguida, selecione todo o texto e torne-o clicável no botão de corrente indicado na imagem abaixo:

![](/assets/img/blog/cadastroweb-inline-4.png)

5.  Aparecerá um pop up pedindo para você criar um link. Cole o mesmo endereço que você colocou na caixa de texto anterior e clique no botão “Criar link”.
6.  Clique em Salvar mudanças e sua atividade está entregue! 🙂

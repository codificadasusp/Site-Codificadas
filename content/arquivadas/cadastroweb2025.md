## Como fazer o cadastro na plataforma de cursos de extensão da USP

1.  Acesse o link [https://cursosextensao.usp.br/login/signup.php](https://cursosextensao.usp.br/login/signup.php)
2.  Crie sua conta utilizando seu CPF e o código de convite: **codificadas2025**
3.  Uma vez logada no site, você verá todos os cursos de extensão que a USP oferece no site. Você pode procurar o nosso curso (São Paulo > IME > Cursos de Verão > Verão 2025 > Programação Web para Meninas).
4.  Na seção “Autoinscrição (Aluno)” insira o código de convite: **codificadas2025**
5.  Pronto, bem vinda ao curso!

## Passo a passo para utilizar o GitHub Codespace

Abaixo, mostramos todas as etapas necessárias para utilizar a plataforma GitHub Codespace, onde será armazenado todos os códigos feitos durante as aulas do curso. 

**Atenção**: Para usar o Codespace, é necessário criar uma conta no GitHub. Caso você não tenha uma, é fácil e rápido de criar. 

## Criação do repositório 

1.  Com a conta já criada, acesse o site [https://github.com/](https://github.com/)

2.  Clique no (+) localizando no canto superior direito e selecione a opção “New Repository”  

3.  Coloque o nome que preferir no repositório e marque a opção “Add README”. Você pode adicionar uma descrição se achar necessário. 

4.  Você pode deixar o repositório público para as monitoras poderem acompanhar. Mas é possível deixar privado posteriormente. 

5.  Clique em “Create repository”. 

## Utilização do Codespace 

1.  Selecione novamente o (+) encontrado no canto direito 

2.  Clique em “New Codespace”. 

3.  Selecione a opção “Select a repository” e escolha o repositório que você acabou de criar e clique em “Create codespace”. 

4.  Para visualizar as páginas no navegador, é necessário instalar uma extensão. Desse modo, selecione a opção “Extensões”, digite “Live Server”, selecione a primeira opção e clique em instalar. 

5.  Para visualizar o código que você escreveu, clique com o botão direito sobre o arquivo em que você quer visualizar e selecione a primeira opção “Open with Live Server”. Assim, você consegue visualizar a página. 

## Salvando as alterações 

Para que as alterações que você fez sejam atualizadas no repositório, é necessário seguir alguns passos: 

1.  Selecione a opção “Controle de Código-Fonte”. Ao selecionada, clique no (+) sobre os arquivos que foram editados.  

2.  Após esses arquivos subirem para o espaço “Alterações preparadas”, no campo “Mensagem”, digite o que você fez com o arquivo.  

3.  Após isso, clique em “Confirmação” e, logo em seguida, clique em “Sincronizar alterações”. É possível perceber que, ao olhar o repositório no Github, as alterações estarão lá com suas respectivas descrições. 

4.  Caso você esteja trabalhando com mais de um arquivo e deseja colocar mensagens diferentes para cada um, basta realizar a etapa descrita para cada arquivo.
